# Provenance and publication status

This portfolio edition derives from an existing personal study application. It retains the substantial study engine, browser persistence adapter, Python/SQLite server, append-only authoring helper, content validator, and behavior/version regression coverage.

The original course library and embedded images were replaced by newly written fictional examples. Real study records, backups, source-history bundles, deployment identifiers, owner configuration and original course documents are excluded. No original app files were changed to create this edition. The public repository starts with a clean history and does not include the private application's history.

The project was developed with AI assistance. The project owner's documented role includes defining the learning workflow, directing product and interface changes, and reviewing behavior. AI agents assisted implementation, migration, test development and portfolio preparation. This record does not claim that the owner personally hand-wrote every component.

## License status

The owner approved public publication of this edition. No open-source license has been selected or granted, so this repository is not presented as open-source software. No original third-party lesson material or embedded course imagery is included.

The shipped runtime uses browser APIs and the Python standard library. Authoring/test scripts additionally use Node.js built-ins. No vendored packages, downloaded fonts, or package dependencies are shipped. Installing or distributing language runtimes remains subject to their respective licenses.
